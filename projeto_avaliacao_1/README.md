# Avaliação 1 

Esse projeto contém o código da primeira avaliação da disciplina de Linguagem de Programação 1 

Para evitar a criação de múltiplas instâncias do Postgres e PGadmin, criei uma configuração de docker compose.

Para executar, basta executar na pasta projeto_avaliacao_1, o comando:

```
docker compose up -d --build
```

[Instalação do Docker Compose](https://docs.docker.com/compose/install/)
